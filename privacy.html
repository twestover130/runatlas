Run Atlas privacy

Run Atlas uses your starting point and requested distance to suggest running routes. You can type a place, tap the map, or grant location access when you select “Use my location.” You can change this permission in your phone settings.

Place searches send the entered text to OpenStreetMap Nominatim. Map tiles are requested from OpenStreetMap for the area on screen. Nearby venue queries send the search area to Overpass. Route requests send coordinates to the Valhalla routing service. These services and the website host receive connection information such as your IP address.

The planner holds search results in memory. When you choose Save route, the route path and start are stored in this browser on this device until you remove them or clear site data. The browser caches app files for reopening. Links to external maps and clubs can include the selected coordinates. External sites handle requests under their own privacy policies.

Contact the Run Atlas developer at support@tripacepro.com.
